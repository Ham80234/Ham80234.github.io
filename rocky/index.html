Running with Local Files

To have this player load audio files directly from your local ./audio/ folder, follow these quick steps:

  1. Create an audio folder in the same directory where this HTML file is saved.
  2. Drop your music files (.mp3, .wav, .ogg, .m4a) into that folder.
  3. Launch a local development server so the browser can read the directory structure:
    # Python 3:
    python -m http.server 8000
    # Node.js (npx):
    npx http-server
  4. Open http://localhost:8000 in your browser!
Note: Modern browsers block direct local file system reads (file:// protocol). Running a lightweight local server is required for directory scanning.
